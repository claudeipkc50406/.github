<p>把「怎么选真实住宅IP」这件事按时间排开，会好办很多：签单前一周只做需求归纳，询价当天只问固定六个问题，拿到试用的第一个小时只做三项检测，上线头三天只盯两个指标，满一个月做一次复盘，续约前再重新评估。每个节点只干几件事，就不会被「伪家宽」「纯净池」这类词牵着走。下面给出每个节点的动作、产出物和判定标准，能看到的东西都给出查询入口。</p>
<h2>一、T-7：先把需求写成一张纸</h2>
<p>不要先看服务商列表。先写清楚：要几个出口、每个出口绑几个账号、所在城市、每天在线时长、单账号月预算上限、需要静态还是可以接受定期更换。这六项写不出来，后面所有报价都没法比。</p>
<h3>把「几个」换算成「几个段」</h3>
<p>如果你需要 20 个出口，问服务商时要说「是否同一 /24」，因为同段20个IP在画像上接近一个出口。真实可用的独立出口建议分散在至少三个不同 /24，最好落在不同城市。</p>
<h2>二、T-3：询价阶段问哪六个问题</h2>
<p>六个问题覆盖了九成踩坑点，逐条问，让对方用文字回答，不要只听口头承诺。</p>

<h2>三、T-1：拿到试用IP的第一小时做什么</h3>
<p>第一小时别急着注册，先把这条线摸清楚。</p>
<h3>三项检测的具体命令</h3>
<p>一是类型检测：curl -s "https://ipapi.is/json/?q=IP"，看 is_datacenter、is_vpn、is_proxy 是否为 false。二是路径检测：mtr -rwzc 200 目标域名，记下末跳丢包和平均延迟。三是出口一致性：连续请求 https://ipinfo.io/json 二十次，看返回的 ip 与 city 有没有变。</p>
<h3>伪家宽的两个硬特征</h3>
<p>第一，whois 里的 org 是某家「网络科技」「数据服务」公司，而不是宽带运营商。第二，traceroute 出去第一跳就是内网地址 10.x 或 172.16.x，且延迟极低。这两点同时出现，基本可以判定是机房转售包装成家宽。</p>

<h2>四、T+3：上线头三天的观察项</h2>
<p>先用两到三个账号做小批量，不要一次把所有账号压上去。三天里只盯两件事：出口IP有没有跳变、单次会话有没有被中断。</p>
<p>记录方式很简单，一个文本文件，每两小时一行：时间、出口IP、延迟、是否掉线、账号是否要求重新验证。三天后看这张表，跳变超过两次就找服务商要解释。这个阶段暴露的问题，处理成本最低。</p>
<p>顺便验证一下切换行为：主动断开一次连接，看重连后是否回到同一个出口。回到同一出口是静态线路的基本要求，跳到别的城市则说明是动态池在调度。</p>
<h2>五、T+30：一个月时的复盘节点</h2>
<h3>三个数的算法</h3>
<p>满月时算三个数：可用率、平均延迟、异常次数。可用率用探针数据算，每分钟一次请求，可用次数除以总次数。低于 99% 就要谈。</p>

<h2>六、T+90：续约前重新评估</h2>
<p>三个月是一个合理的评估周期。这时候你手上有真实数据：可用率、投诉次数、账号状态变化。拿这些去比价，比拿宣传页面比价靠谱得多。</p>
<p>评估三个维度：单价是否还在合理区间（静态住宅常见 50 到 200 元每个IP每月，仅供参考）、同段邻居有没有变脏、售后响应是否还在承诺时限内。三项里有两项变差，就该考虑换供应商，而不是等合同到期。</p>
<h2>常见问答</h2>
<h3>试用期一般给多久比较合理？</h3>
<p>答：三到七天足够跑完类型检测、路径检测和出口一致性三项。只给几小时或者要求先付全款的，通常不愿让你看到真实数据，建议谨慎。</p>
<h3>共享池一定不能用吗？</h3>
<p>答：看用途。临时查资料、做公开页面测试，共享池够用。但长期绑定的账号不建议放在共享池，因为出口会在你不知情时换人，登录地记录会变得混乱。</p>
<h3>询价时对方不肯给ASN，怎么办？</h3>
<p>答：ASN 是公开信息，不涉及商业机密。连这个都不愿提供的，通常资源来源不清晰。可以直接要一段样例IP，自己查 whois 和 ipinfo，比问更有效。</p>
<h3>一个月复盘发现可用率只有97%，还有必要留吗？</h3>
<p>答：先分清是线路问题还是本地网络问题。用两台不同网络的机器同时探测，如果只有一台掉线，问题在本地；两台都掉，才是线路。确认是线路后再谈补偿或更换。</p>
